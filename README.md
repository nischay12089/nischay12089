## About Me

I'm a developer focused on **Android application development**, **software engineering**, and **Android platform customization**. I enjoy working across the stack: from user-facing applications to the lower-level services and frameworks that power Android devices.

My work includes investigating complex platform issues, debugging vendor integrations, exploring reverse engineering, and creating practical tools and automation. I use **Claude Code** and **OpenAI Codex** as professional coding assistants for research, implementation, code review, debugging, and iterative problem-solving — while keeping engineering decisions and validation grounded in the actual code and system behavior.

## Areas of Focus

- **Android applications:** App architecture, feature development, UI implementation, and debugging.
- **Software development:** Designing, implementing, maintaining, and improving software solutions.
- **Custom Android ROMs:** OEM ROM porting, framework integration, system configuration, and compatibility work.
- **Android internals:** HALs, AIDL services, vendor components, system properties, and SELinux policy analysis.
- **Reverse engineering & diagnostics:** Investigating native components, system logs, and platform behavior.
- **Automation & tooling:** Building scripts and developer workflows to make repetitive engineering tasks more reliable.

## AI-Assisted Engineering Workflow

I use **Claude Code** and **OpenAI Codex** as part of my day-to-day engineering process — not as substitutes for understanding the codebase, but as tools for working through complex development tasks more effectively.

| Workflow | How I use AI coding agents |
| --- | --- |
| Codebase exploration | Trace dependencies, understand unfamiliar modules, and identify relevant implementation paths. |
| Implementation | Develop features, services, utilities, and scripts from clear technical requirements. |
| Debugging | Analyze logs, investigate failures, and evaluate possible root causes. |
| Refactoring | Improve code structure, readability, and maintainability. |
| Review & validation | Examine changes, identify edge cases, and plan tests before integration. |
| Documentation | Maintain technical notes, implementation plans, and project documentation. |

> **My approach:** Understand the problem → plan the solution → implement carefully → test and iterate.
